# Staccato Live Chat Demo

Standalone React demo for the Staccato Music live chat concept.

This repo does not import the existing Marching Band App codebase. It only recreates the proposed live chat UX as an isolated, clickable prototype for client review.

## Run

```bash
npm install
npm run dev
```

## What is included

- Separate `Web App` and `Mobile App` preview tabs, so each flow can be reviewed independently.
- Desktop web chat layout with sidebar, conversation list, active thread, and context panel.
- Mobile/native-style chat preview with list/thread navigation.
- Role switcher for Member, Section Leader, and Director.
- Mock section announcements, live messages, SMS composer state, and delivery status.
